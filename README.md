## 📖 About the Project

SonicPulse Backend is a full-featured server-side application built to bridge the gap between artificial intelligence and music streaming platforms. 

The application allows users to prompt an AI with a specific mood, vibe, or scenario, processes the request via **Google Gemini AI**, matches the tracks using the **Spotify Web API**, integrates rich audio previews via **Apple Music**, and automatically generates a customized playlist directly in the user's Spotify account.

This project was built to gain practical, hands-on experience with enterprise backend architecture, external API integrations, OAuth authentication flows, and AI-driven data processing within the Java ecosystem.

---

## ✨ Features

- **🤖 AI-Powered Curation**
  - Seamlessly integrates with Google Gemini API to interpret creative user prompts and generate tailored music recommendations.
- **🎵 Multi-Platform Music Integration**
  - Handles secure Spotify OAuth authentication, track searching, and automated playlist creation.
- **🎧 Apple Music Previews**
  - Fetches and embeds rich media data and audio previews using Apple Music.
- **🛡️ Secure REST API**
  - Provides robust, structured endpoints designed for clean communication with the frontend client.

## 🛠️ Tech Stack

- **☕ Java 17+ & Spring Boot**
  - Used for developing RESTful APIs, structuring business logic, handling HTTP requests, and managing service layers.
- **🧠 Google Gemini API**
  - Acts as the core AI intelligence engine for understanding user prompts and generating track lists.
- **🎧 Spotify Web API & Apple Music**
  - Used for music catalog searching, audio previews, and user playlist management.
